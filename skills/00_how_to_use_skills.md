# Cómo usar las Skills del proyecto

Cada skill es una instrucción específica para agentes de IA. Antes de pedirle al agente que programe un módulo, dile qué skill debe leer.

## Orden recomendado

1. `AGENTS.md`
2. `docs/00_master_plan.md`
3. `docs/02_prd.md`
4. Skill específica.

## Ejemplo

```text
Lee AGENTS.md, docs/03_architecture.md y skills/pdf_ocr_extraction/SKILL.md. Luego implementa el módulo PDF/OCR.
```

## Regla

Una skill no reemplaza la documentación general. La skill dice cómo trabajar en una tarea concreta.
