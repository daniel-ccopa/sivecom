# 01 - Project Brief

## Resumen ejecutivo

SIVECOM es un sistema web de apoyo administrativo para revisar expedientes PDF de conformidad de servicios. Su objetivo es automatizar tareas repetitivas como lectura de documentos, extracción de datos, comparación de montos, verificación de fechas y detección de documentos faltantes.

## Propuesta de valor

- Reduce el tiempo de revisión de expedientes.
- Disminuye errores humanos.
- Permite trazabilidad de cada alerta.
- Facilita auditoría interna.
- No exige que el proveedor separe documentos.
- Puede funcionar localmente en una municipalidad.

## Flujo general

1. El administrativo sube un PDF.
2. El sistema divide el PDF por páginas.
3. Extrae texto directo u OCR.
4. Clasifica cada página.
5. Extrae datos relevantes.
6. Aplica reglas.
7. Genera alertas.
8. Muestra dashboard.
9. El usuario toma la decisión final.
10. Se exporta informe.

## Tipos de documentos esperados

- Carta de solicitud de conformidad.
- Orden de servicio.
- Comprobante de pago, factura o recibo por honorarios.
- Informe de actividades.
- Anexos fotográficos.
- Constancias o documentos adicionales.
- Firmas y sellos.

## Resultado esperado

Un expediente procesado debe tener:

- Estado de procesamiento.
- Documentos encontrados.
- Datos extraídos.
- Validaciones aprobadas.
- Alertas detectadas.
- Veredicto sugerido.
- Decisión final humana.
