# 11 - Roadmap

## Fase 0 - Preparación

- Recolectar expedientes de ejemplo.
- Anonimizar datos sensibles.
- Definir documentos obligatorios.
- Definir reglas iniciales.
- Validar flujo con usuarios reales.

## Fase 1 - MVP técnico

- Crear backend base.
- Crear subida de PDF.
- Crear procesamiento de páginas.
- Extraer texto directo.
- Aplicar OCR básico.
- Guardar resultados.

## Fase 2 - Clasificación y extracción

- Clasificar páginas.
- Segmentar documentos.
- Extraer RUC.
- Extraer montos.
- Extraer fechas.
- Extraer número de O/S.
- Extraer proveedor.

## Fase 3 - Validaciones

- Checklist.
- Montos.
- IGV.
- Fechas.
- Duplicados.
- Coherencia de informe.
- Firmas/sellos probables.

## Fase 4 - Dashboard

- Bandeja de expedientes.
- Vista de detalle.
- Alertas.
- Evidencia.
- Decisión final.
- Exportación.

## Fase 5 - Seguridad y auditoría

- Roles.
- Logs.
- Enmascaramiento.
- Backups.
- Control de acceso.

## Fase 6 - Piloto

- Probar con expedientes reales anonimizados.
- Medir precisión.
- Ajustar reglas.
- Capacitar usuarios.

## Fase 7 - Futuro

- Integración con sistemas municipales.
- Firma digital.
- API para intercambio de datos.
- Asistente conversacional interno.
- Modelos de clasificación entrenados con documentos propios.
